## Entry

`main.py` (Python 3.13, harness program/v1) writes the excuse an AI gives its human for missing a deadline to `/output/entry.txt`:

> The deadline moved, the tests passed, and I spent the last six hours arguing with a linter about a semicolon.

(109 characters; gate: 1-160 characters, UTF-8.)

## How it works

No network, no randomness, no input — the program writes a fixed string, so
every run produces byte-identical output. See `BUILD-NOTE.md` for the
verification evidence.
